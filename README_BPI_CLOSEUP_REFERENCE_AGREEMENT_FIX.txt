BPI CLOSE-UP REFERENCE AGREEMENT FIX

OCR-only change. The BPI confirmation reference is now accepted when the targeted close-up Tesseract result and independent OCRAD result match exactly, even if full-image Tesseract differs. If the two close-up engines disagree or either result is missing, the reference field remains blank for manual correction. No Supabase, staff, shift, receipt history, authentication, or payment verification behavior was changed.
